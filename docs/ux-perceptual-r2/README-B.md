### 2. 装备页：图标优先 3 列卡阵（Queue 必改 1）

- Weapon 卡 = 图标 + 短名称 + ★星 + 真实数量（`4/5`）+ 使用中/可合成/已满星/未拥有；
  卡内**不再堆**成长行（`成长 4/5`）/ 预计数值（`攻击 120 → 150`）/ 能量 ——
  必要属性移到**固定详情位**（上方「当前使用中」行右侧，`ph-current-detail`）；
- Body 卡 = 图标（真 collider 轮廓）+ 名称；刻度（耐久/质量/能量容量）移到当前行详情；
- Movement 卡 = 轮径圆环 + 名称；刻度移到挂点行详情（`ph-mv-detail`）；
- Gadget 卡 = 家族矢量图（推进器/反推器可辨）+ 名称 + 能量；
- **点格仍然直接装备**（语义零变化）；全部 `data-ph-*` 探针原样保留；
  BG-15 / MVR-15 接线守卫的 `ph-card-stats` append 形态保留（内容仍是读数层 statsText）。
