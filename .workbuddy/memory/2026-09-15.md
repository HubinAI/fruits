## PRP-BUILD-01-R2-RECOIL-BUILD-NATURAL-CAUSALITY（反冲蓄能：前推 → 强后坐）

### 0. 背景 / 真人验收结论

- 真人批量验收：`重型弹头 → 动能爆发` ✅ **冻结**；`双联炮 → 三连装填` ✅ **冻结**；
  `快速装填 → 反冲蓄能` ❌ **未通过**。
- 原话：「录像中能够看到周期性前移，但正常速度下无法自然理解 **高频开炮 → 储存反冲 → 向前推进**；
  它容易与正常接敌 / Collision / Camera movement 混在一起。」
- Queue 要求：**停止继续调「向前推进」的强度**，把第二层改成自然物理因果
  （高频开炮积累反冲 → 达到阈值 → **一次明显向后强后坐**），形成「高频射击 / 主动控距 Build」。

### 1. 调查（先调查，不改码）

- 接缝定位：`runBuildAbilities.ts:187-208` 的 `weaponFire` 分支 —— 蓄满 `RECOIL_CHARGE_THRESHOLD(3)`
  后 `pending.push({ dirX: this.ports.facingOf(PLAYER_TEAM), dirY: 0, magnitude: 45, at: null })`
  → **方向 = 自身朝向（向前）**，作用点 = 质心。这就是「向前推进」的唯一落点。
- 关键便利：**同一分支上方两行已经记录了本次开火的真实炮口方向**
  （`ev.worldDirection` → `lastFireDirX/Y`）与（本轮新增）真实炮口位置（`ev.worldPosition`）
  → 改向**不需要新接缝**，取反即可。
- 冻结项确认：`fastReload` 的 overlay 只改 `cooldownMs: 650`（不改武器其它字段），
  `recoilCharge` 的 `affectsWeapon: false`、`behaviorParams: {}` → 本轮只动「能力侧」冲量。

### 2. 决定性发现一：旧口径的根因**不是幅度，是方向与接敌同向**

实测（真实 Runtime + 正式相机链，A = `['fastReload']` vs B = `['fastReload','recoilCharge']`）：

| 口径 | 20 帧净后移 | 每次触发位移 | 同局自然抖动基线 |
|---|---|---|---|
| 旧（前向 45，仅换向后仍未放大） | **0.7px** | +21 … −7px | **−12.1px** |

→ 旧口径的位移**低于同局自然抖动**（碰撞推挤 / 普通后坐），**结构上不可能被读出来**；
   且方向与「我本来就在前进」叠加 → 无法从接敌里分离。这才是「混在一起」的物理原因。

### 3. 决定性发现二：质心冲量 = 纯平动 → 被相机追平（R1 根因一重演）

先把 `at` 保持 `null`（质心）只换方向 + 放大，实测：

| 冲量 | 世界位移（踹开） | **舞台带位移** |
|---|---|---|
| 250 | −20 … −27px | **−3.6 … −4.5px** |
| 300 | −21 … −29px | **−4.4 … −4.9px** |
| 350 | −8 … −32px | **−0.5 … −5.3px** |

→ 世界后退 20~32px，**舞台带只动 3~5px**：与 PRP-BUILD-01-R1 的根因一完全同型
  （`applyBattleFollow` 追踪双方中点 → 平动被追平）。
⚠️ 结论：**继续加力不是出路**（要可见就得把车推到墙上）。

### 4. 决定性发现三：炮口作用点确实产生扭矩，但对**重的玩家车**微不足道

改用真实炮口位置作作用点（`weaponFire.worldPosition`）+ 方向取反后，
做了一次决定性实验（对玩家车施加 3000 的炮口冲量）：

```
immediate: dW=-0.2866 rad/s  dVx=-25.000
afterStep: angle=-0.0796 rad (= -4.56°)  W=-0.0827
```

→ **扭矩通道存在**（力臂有效）。但换算到 450 的真实冲量，角度只有 **0.0~1.2°**
  —— 因为玩家车（西瓜重车）质量/惯量远大于 R1 里被轰开的敌车（ProtoRusher）。
⇒ **R2 的可感知通道不是扭矩，而是「平动位移 + 双方距离」**：
  相机只做平移，**两车间距在屏幕上是等价的**（世界距 × scale），不被追平。

### 5. 定值 `RECOIL_CHARGE_IMPULSE = 450`（由既有不变量夹出的上界下沿）

统一口径（炮口作用点，真实 Runtime + 正式相机链）实测扫描：

| 冲量 | 每次踹开（世界 px） | 玩家左缘最小 bandX | 净后移 | 战斗步数 | 第一场残血 |
|---|---|---|---|---|---|
| 45（旧值，仅换向） | +21 … −7（淹没在噪声里） | 30.50 | 0.7 | 586 | 967 |
| 300 | −5 … −29 | 30.50 | 73.4 | 586 | 1091 |
| **450** | **−11 … −46（中位 ≈−28）** | **9.24** | **314.5** | 830 | 1060 |
| 500 | −6 … −52，另有一次 **+58.6 反弹** | **−2.01（越界）** | — | 937 | **403** |
| 550 | −18 … −67，另有一次 **+58.6 反弹** | **−1.58（越界）** | — | 1002 | **0（阵亡）** |

取舍（不是口味）：
1. **可感知**：中位 ≈28px 世界 = 自然基线 12.1px 的 **2.3 倍**；距离同步拉开 6~45px。
2. **不越界**：500/550 把玩家左缘推出舞台带（`bandLeftMin < 0`）→ 破坏「完整入画」；450 留 9.24px。
3. **不伤 Run 连锁**：500 → 403、550 → **阵亡**（破坏 RUN-R1「三场都活着且有余量」）；450 → 1060。
4. **不引入退化观感**：500+ 出现 **+58.6 的正向跳**（撞左墙被弹回）——「被墙弹回来」不是「被后坐踹开」。
⚠️ 500 → 550 恶化极陡（403 → 0）⇒ 本冲量对战果**强混沌**，不能靠继续加力做平衡。
