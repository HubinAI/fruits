### 关键物理结论（Matter 固有限制，多轮实验定位）

1. **旋转滚轮能产生"卷"力，但无法抬升目标（wheel 离地）**：滚轮旋转的摩擦"卷"力，被目标的 wheel constraint（revolute joint）+ 重力抵消。滚轮只能让目标 body 绕 wheel 支点旋转（姿态变化 13°~19°），无法把 wheel 抬离地面。
2. **接触点几何决定抬升/下压**：接触点在滚轮中心左侧 → 切向朝下（下压）；右侧 → 切向朝上（抬升）。但即使几何正确（接触点在右侧），"卷"力仍不足以抬升（wheel 约束 + Matter 位置修正 vs 摩擦耦合）。
3. **抬升瞬间在手工 createBox（无 settle）下存在（12px），但真实 createVehicle（settle + wheel 约束）下消失**。
4. 根因：Matter 碰撞求解器的位置修正（把 body 分开）和摩擦（切向力）耦合，切向"卷"力无法有效传递为抬升。

### 验收结果

### 遗留风险（Foundation 级，需知会）

2. 这是"Spin + Force/Posture"的核心成立，但"Spin + 抬升（Launch 式）"需要换物理引擎或改装配方案
3. 与 Push Rod（Queue 04）同类：持续施力 + 软约束 → velocity 累积 + 穿透，是 Matter 全局隐患
