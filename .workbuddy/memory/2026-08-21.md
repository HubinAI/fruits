## F-PRESENT-1｜高频 Damage Number 聚合（已提交 + 推送 fc30682）

- **问题**：Q14-A 机枪(-20)/Q14-B 喷火器(-8) 高频真实伤害，每个 damage event 都触发一个浮动数字，
  大量数字停留 ~900ms 形成红色数字云，遮挡武器主体。
- **方案（仅 Presentation/Renderer，Gameplay 完全不变）**：
  - 新增纯聚合器 `src/presentation/damageNumberAggregator.ts`（无 Canvas/无 Gameplay 依赖，易测）。
  - 分组键 = `target|source|(partId ?? behavior ?? damageSource)`；固定窗口 **210ms**，
    以该组「首次命中时间」为起点，**不得每次命中无限延长**。
  - Renderer `spawnDamageNumberFromEvent(ev)`：窗口内合并 → 原地更新浮动数字 text（累计真实伤害）
    + position（跟随最新 contactPoint），不新建；首击/窗口到期 → 立即新建浮动数字（单发零延迟）。
  - `main.ts` 的 `onDamageNumber` 改为调用 `renderer.spawnDamageNumberFromEvent(ev)`；
    `onDamageNumber` 仍每个真实 damage event 各调用一次（调用次数与聚合无关）。
  - 新增 `renderer.activeDamageNumbers` getter（镜像已有 active*Fx getter，供测试断言）。
- **验收**：喷火器 4 连击 → 1 个数字(-32)；机枪 7 发 burst(100ms) → 3 组数字；Cannon 单发立即显示；
  damage 总量守恒；Gameplay/HP/Resolver/Weapon 参数/hit flash 全部未改。
- **禁改项均守住**：未改 Damage Resolver / HP / Weapon 参数 / hit flash / collision / CombatEvent 字段 / 依赖。
- 测试：`tests/damageNumberAggregation.test.ts`（9 cases）。回归：battlePresentation / rendererProjectile /
  machineGunScenarios / flamethrowerScenarios 共 26 全过；`tsc --noEmit` 0 errors。
- 提交 fc30682，推送 `c7cf242..fc30682`（分支 foundation-02-canonical）。
