## Q13-B｜霰弹炮 Weapon（已实现）

- 体验目标：与普通炮（单发稳定弹道）形成完全不同的远程选择 —— 炮=单发稳定；霰弹=近距离扇形爆发。
- 核心决策：**不新建第二套 Projectile 系统**。抽 `src/battle/weaponProjectile.ts` 的
  `spawnWeaponProjectile`（从 Cannon/Laser 抽取的共享唯一真实弹生成点），Shotgun 仅负责
  「何时发射 / 朝哪些方向 / 发几发」，弹体生成 / 归属 / CCD / ContactRouter 伤害结算全部复用同一条正式链路。
- 改动：
  - `src/battle/weaponProjectile.ts`（新）：共享 `spawnWeaponProjectile(world, vehicle, part, {dir, muzzleSpeed, projectileRadius, projectileMass, gravityScale?})`；返回 `{proj, muzzlePoint}`；碰撞过滤 PROJECTILE 类别 mask GROUND|ARENA|HAZARD|敌方类别 + 同队负 group（不碰己方）；初速度 = 射手线速度 + dir×muzzleSpeed。
  - `src/battle/shotgunBehavior.ts`（新）：`ShotgunBehavior`。每次开火同时生成 5 发真实 projectile，
    固定扇形 `fanAnglesDeg:[-12,-6,0,6,12]`（相对炮口基准方向，由 part 世界姿态 + facing 推出；无随机 / 不自动瞄准 / 不 raycast）；
    一次齐射只发 1 次 `weaponFire` 事件（驱动一次爆闪）+ 只 `applyLinearImpulse` 一次 recoil（沿基准反方向作用于真实炮口点，由 Weld 传给整车；禁 setLinearVelocity）。
  - `src/battle/behaviorRuntime.ts` + `behaviorRegistry.ts`：注册 `createShotgunRuntime`（behavior 'shotgun'）。
  - `src/core/content.ts`：新增 `shotgun` def（weapon / box collider 46×22 offset{23,0} 短粗枪管 / behavior 'shotgun'；
    behaviorParams：`cooldownMs:1300, muzzleSpeed:6`（< Cannon 8，射程偏近、自然散开）, `projectileDamage:30`, `projectileRadius:7`,
    `projectileMass:1`, `recoilImpulse:45`, `fanAnglesDeg:[-12,-6,0,6,12]`）。加入 registry map。
  - `src/core/partOptions.ts`：PART_OPTIONS 加 `{v:'shotgun', t:'霰弹炮'}`（进正常 Build）。
  - `src/lab/buildEditorModel.ts`：EDITABLE_FUNCTIONAL_DEF_IDS 加 'shotgun'。
  - `src/lab/scenarios.ts`：新增 `shotgunCarBuild()`（watermelon + front shotgun）+ `Q13-B` Scenario（A 霰弹炮 / B 无攻击件目标车，spawn 450/1150）。
  - `src/main.ts`：onMuzzleFlash 加 `shotgun` 分支 → 暖橙 `#ffd35a` 半径 16 更大爆闪（Cannon 默认小闪 / Laser 白青巨束不变）。
- 禁止项全部遵守：无随机散布（首版可复现）/ 不自动瞄准 / 不做扇形 raycast / 不复制第二套 Projectile 系统 / 不改 Cannon·Laser。

## Q13-C｜推进器 Gadget（已实现）

- 体验目标：玩家一眼看到「推进器喷火 → 整辆车突然向前冲」；改的是距离/碰撞时机，不直接造成 Weapon Damage。
- 核心决策：**推进器 = Weld part**（与 Cannon/Shotgun 同路，`planckVehicleAssembly` 的 `!== 'hammer' && !== 'lifter' && !== 'saw'`（且非 pushRod/rammer）→ `createWeldJoint`，无需改装配/关节）。推力 = 每个固定步施 1 次 `applyLinearImpulse`（≡连续力 via Δv/step，禁 setVelocity/teleport），沿真实 chassis facing 方向，只作用于自己 chassis。喷焰走 snapshot（非事件）：`battleContract` 加 `RenderFlame` + `BattleRenderSnapshot.flames`，orchestrator 聚合 `getRenderFlames?()`（镜像 `getRenderProjectiles`），renderer `drawFlames` 在真实安装位置画短喷焰；停推即空数组 → 自动立即消失。
