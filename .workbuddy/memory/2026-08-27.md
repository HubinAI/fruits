## 真实链路（反向 layoutRect → 可见像素）
- `ensureSize()`（`:784`）：`this.scale=min(cssW/BASE_W,cssH/BASE_H)`，`this.ox=(cssW-1280*scale)/2`，`this.oy=(cssH-720*scale)/2`（desktop 档）。

- 可见 CSS 位置 = `this.ox*(1+this.scale) + this.scale²·x`（device/dpr）；而 `screenToLayoutPoint` 反推假设 `css = this.ox + this.scale·x`。
- 二者仅当 `this.scale===1`（player/mobile-normal/short）时一致；`this.scale≠1`（desktop 大屏 1920×1008 → scale≈1.4）时**可见像素 ≠ 命中区** → 真实录屏错位（点可见控件中心不响应、点其左侧空白反而命中）。

## 已定位差异点（根因）

## 修复已实施（:839）
