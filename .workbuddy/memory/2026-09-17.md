### 坑（本轮踩到的，已写进 MEMORY §3）
1. **probe 的浮层三项必须走「本帧实际口径」**：种子浮层打开时 state 仍是 `COMPLETE`
   ⇒ `runOverlayOpen(state) === false` ⇒ 若 probe 沿用原式会报「屏幕上没有浮层」而实际整页是浮层。
   同理 `actionLabel` / `actionEnabled`（验证停止态必须报不可用，否则 probe 报出一个不存在的按钮）。
2. **账本必须与「本帧真正画的东西」一致**：种子浮层时 `runPageLayerShapes(state)` 会登记一批
   被遮罩盖掉的层 ⇒ `layeredShapes()` 必须在种子浮层时只返回 `cardBar`；验证停止态要过滤 `actionBar`。
3. **「整页重压暗」的阈值不能取高**：页面底色本身极暗（日志带合计仅 57），
   0.86 深色遮罩对暗底的绝对降幅上限小（实测最小 26）→ 阈值取 15；取 60 会假红。
4. **R22a 的 `labSourceFiles()` 只扫 Lab 顶层 `.ts`** ⇒ 新文件**必须**放 Lab 顶层，
   放子目录会**绕过 import 白名单守卫**（本轮刻意验证 `validation/` 目录不存在）。
5. **根目录 html 清单是冻结断言**（`portraitDefaultEntry.test.ts` R2-10）⇒ 新增 html 必须显式更新。
6. **RP-RUN-02-05 守卫断言源码字面量**：改实现后**必须强化守卫而不是放宽**
   （本轮把「三处都直读 `runOverlayCards`」收紧为「全文件只有一个调用点 + 三个调用点都经唯一入口」）。
