## 《最强水果》第一阶段 Physics Foundation 搭建完成

**项目背景**：《最强水果》是全新 IAA 项目，核心是「玩家事前组装机器 → 二维物理自动战斗」。本阶段只搭 Foundation，不扩正式水果/Weapon/Gadget Content。

### 技术选型

- 物理引擎：**Matter.js**（成熟 2D 刚体方案，纯 JS headless 可测，内置 debug renderer，类型齐全）

### 核心模块（src/）
- `core/types.ts` + `content.ts` + `buildSnapshot.ts` + `buildValidator.ts`：Body/Movement/FunctionalPart 定义、Build Snapshot、Build Validator（槽位/类型/Energy 超载拒绝/至少1武器）
- `physics/adapter.ts`：唯一依赖 Matter 的入口，封装世界/固定步进/body/joint 工厂/碰撞事件归一化
- `battle/vehicleAssembly.ts`：真实装配（Body compound + Wheel 独立体 + Fixed Mount weld），聚合 COM/Inertia

- `battle/contactRouter.ts` + `damageResolver.ts` + `combatEvents.ts`：Contact→Impact→Damage→CombatEvent 链路

- `lab/presets.ts` + `scenarios.ts` + `physicsLab.ts`：6 Preset + 5 Scenario，直接调用正式 Runtime
- `render/renderer.ts` + `debugOverlay.ts`：渲染 + Debug 显示/时间缩放/Override

### 关键坑（务必记住，后续迭代会用到）
1. **Matter.Body.create({parts}) 会按 parts 的 COM 重算 position**，覆盖传入的 position → 必须 `Body.setPosition` 显式设置。
2. **Matter 默认 gravity.scale=0.001 太小**，轮子摩擦牵引力不足 → 提到 0.01。
3. **Matter 的 Coulomb 摩擦对「纯滚动」的法向力（源于穿透）在静态平衡趋近 0**，单靠 setAngularVelocity 无法驱动整车 → 接地轮额外施加 applyForce 真实水平牵引力（driveForce=0.005，非假移动）。
4. **revolution joint stiffness=1 会导致落地翻车** → 用 Matter 默认 stiffness=0.7 + damping=0.1。
5. **Arena Closing 刺墙若用巨大质量动态体（mass=100000）会破坏世界稳定性** → 初始 setStatic(true)，Closing 阶段再激活。
6. **多辆车共享 world 时，Matter 的 pair id 递增导致浮点非确定性**，落地姿态会分叉（翻车 vs 稳定）——这是 Matter 固有限制，Scenario C 的落地稳定性属第三层体验验收，留待后续调参。
