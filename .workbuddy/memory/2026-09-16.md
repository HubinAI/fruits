## 1. 为什么 R2 的 450 也会失败（先调查后改码的结论）

## 2. 三条实测结论

1. **正式相机是「可感知性」的第一约束**：`applyBattleFollow` 对双方 envelope 求 `midX` 居中 +
   0.2/帧平滑 + 世界左界 clamp + `offsetY` 补偿 ⇒ **玩家被推退 与 敌车冲刺 互相抵消**。

2. **强度线性可换**：`Δv ≈ 冲量 / 200`（世界 px/帧）。110 = 基础后坐 30 的 **3.67×**（倍数级）。
3. **上界由「保留真实接敌」夹住**：`tmpChainProbe` 决定性实验 ——
   V=0 末场挨打 23 次 / V=110 挨打 4 次 / V=120 挨打 **0 次（零接触，已否决）**；
   V=130、150 直接 `左缘 bandX < 0` 越界 + 末段 HP 0（被自己后坐打死）。

   （斜撞会读成横向），不是弹道。作用点则严格用本次命中**自己的** `contactPoint`。
2. **`soloA: true` 不能做「miss 不触发」判据**（实测敌人仍被命中 4 次）
   → 改用**合成事件注入**直测 `RunBuildAbilities(ports, build)`（记录型假端口，纯逻辑确定性），
   可逐条否掉四条禁止路径：开炮无命中 / 非 weapon 来源 / 反向命中 / 非 cannon。
3. **计数点 = `flush()` 的真实施加处**（`isFinished` 之后），与 `kineticHits` 同一纪律
   ⇒ 240 帧内 `suppressionHits === hits` 严格相等；两个「开炮不触发」指纹 = `hits < fires`、
   `firstHitStep > firstFireStep`。
