## 1. 为什么 R2 的 450 也会失败（先调查后改码的结论）

- 物理上 450 **确实真实生效**（真人自己确认「450 impulse 真实改变双方距离」）。
- 真人读不出来的是「**这是累计 3 次开火后触发的那一次**」——
  正常速度下它和普通 Cannon recoil / Enemy 接敌 / Collision / Camera follow 混在一起。
- **根因 = 不可见的累计状态**：玩家看不到「2/3」，只能看到一串相似的开炮。
  ⇒ **自然因果优先于幅度**：一炮一后坐，因果锚点变成「炮弹离膛」这一可见事件。

## 2. 三条实测结论

1. **正式相机是「可感知性」的第一约束**：`applyBattleFollow` 对双方 envelope 求 `midX` 居中 +
   0.2/帧平滑 + 世界左界 clamp + `offsetY` 补偿 ⇒ **玩家被推退 与 敌车冲刺 互相抵消**。
   实测每炮 **6~10 世界 px → 舞台带仅 1~3 px**。⇒ 靠加大数值换屏幕可见 = 只能把车推到墙上。
2. **强度线性可换**：`Δv ≈ 冲量 / 200`（世界 px/帧）。110 = 基础后坐 30 的 **3.67×**（倍数级）。
3. **上界由「保留真实接敌」夹住**：`tmpChainProbe` 决定性实验 ——
   V=0 末场挨打 23 次 / V=110 挨打 4 次 / V=120 挨打 **0 次（零接触，已否决）**；
   V=130、150 直接 `左缘 bandX < 0` 越界 + 末段 HP 0（被自己后坐打死）。
