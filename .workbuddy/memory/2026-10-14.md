- **根因判定（证据）**：
  ① **产品 Run 全链零 RNG**：脚本 = 固定线性链 ProtoRusher→Chaser→RangedTurret（`runScript.ts:194/216/239`）；

     （`playerGameRuntime.ts:797`），**不在产品 Run 里**；物理 = 固定步累加器（`planckWorld.ts:1017`）+
     settleToGround 消出生分叉；战斗契约明令禁 Math.random。W-02 同参数复跑 3 次逐字相同（机器证明）。
  ② **装配链无丢失**：Garage 存档 → `buildAdventureHref(equipped=)`（含 rearWheelDefId/frontWheelDefId，
     `encodeRunLoadout`）→ Run 探针/`buildSpawnPlanFromDraft` → `resolveEntity.movements` 全链同一真源；
     `equipMovement` 同步写 radius。E2E 的 `front:none rear:none` 是**误读** functionalSelections
     （functional 硬点≠轮组）——已修：轮组改读出发 URL `equipped` 载荷 + 存档，三源一致性断言（A6/D4）。
  ③ **真凶 = 帧批次粒度敏感性（B：环境时序，不是状态 Bug）**：W-03 实测同场战斗按不同 rAF 帧时长驱动
     **胜负翻转**——mango+mg vs Chaser 在 16.67ms/60fps 玩家赢（剩 762），**32ms 玩家输（HP=0）**；
     8ms/64ms 又都赢。机制：`runPage.ts:1612` 用 `Math.min(64, now-lastFrameMs)` 喂 `world.step`，
