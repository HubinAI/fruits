- Node ≥ 24（`engines`）+ `npm ci`；无 `.gitattributes` ⇒ 建议 `core.autocrlf false`。
- clone 后**没有** `dist-portrait-lab/`，任何 E2E 先 `npm run build:portrait-lab`。
- vitest 逐文件串行 `--pool=forks --maxWorkers=1`；E2E 串行（Garage V2 固定端口 8742）。
- 浏览器只走 `tests/_browser_launch.cjs`（Windows 默认 Edge，避免 macOS 那种 `msedge` 硬编码炸掉）。
