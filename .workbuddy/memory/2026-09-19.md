## PBL-FOUNDATION-RANGED-DISTANCE-CONTROL-R1｜交付（远程敌人的「维持作战距离」）

**基线 HEAD**：`db36ad3`（M2-R1 的 memory 补正 commit）｜分支 `prototype-portrait-battle-lab`

### 1. 真人现象 → 根因（先调查，未先改码）

真人验收 Encounter Batch：ProtoRusher / Chaser 通过；**RangedTurret 未通过** ——
失败原因**不是**射击不可见，而是「远距离射击身份清楚 → 数秒后迅速贴脸 → 退化成近战碰撞」。

**实测（改前，`RunBattleRuntime({encounterId:'RangedTurret'})` 逐帧）**：


⇒ 不只是玩家在接近：**敌人自己从 1200 一路开到 885**（5 秒内跨越 315px）。

### 2. 根因：正式编排器里**没有「往哪开」这一层决策**

逐层落地（必改 1 的六个环节）：

| # | 层 | 结论 | file:line |
|---|---|---|---|
| 1 | Enemy AI / Movement decision | **不存在**（只有开关，没有决策函数） | — |
| 2 | target distance | **不存在**（无任何距离读取） | — |
| 3 | desired movement | **不存在** | — |
| 4 | motor / wheel | 有真实实现（`drivePlanckVehicle`：rpm + torque + grip） | `planckMovement.ts:41` |
| 5 | Physics result | 真实（Planck wheel motor → 牵引） | — |
| 6 | **接线点（断的）** | `drivePlanckVehicle(world, vehicleB, { enabled: true, worldDirection: **-1**, targetSpeedPxPerStep: 1.5 })` —— **恒朝玩家、恒定速度的硬编码** | `planckBattleOrchestrator.ts:359` |

关键事实链：
- `RunBattleRuntime` 传**空 config `{}`** ⇒ `resolveDriveEnable(undefined, undefined)` ⇒ `{a:true,b:true}`
  ⇒ B 侧每步无条件驱动。
- 正式对手池 `OPP-03`（= RangedTurret 的模板）**确实声明了 `drive: 'stationary'`**（`opponentPool.ts:64`），
  但 `SpawnedEntity.drive` **只被 `arenaA.ts` 消费**（那是另一套 PRP 竞技场），
  在 `RunBattleRuntime → PlanckBattleOrchestrator` 这条链上被**算出来就丢掉了**。
  ⇒ **数据说「停驻」，运行时说「冲锋」。**

⇒ 缺口 = **远程敌人缺少「维持合理作战距离」的 Movement Foundation**（`decideArenaAAction` 里有
三段距离逻辑，但它在另一套 runtime 里，且 `!self.mobile` 时直接 return）。

### 3. 实现（底层能力，数值只有一个真源）

**新 Foundation 模块 `src/battle/enemyDrive.ts`**（纯函数、**零 import**、无任何物理对象）：

| 档 | 条件（core 间距 gap） | 下发 |
|---|---|---|
| `far` | `gap > 480` | `enabled:true` · 朝对手 · **1.5**（= 既有 autoDrive，逐项相同） |
| `hold` | `240 ≤ gap ≤ 480` | `enabled:false`（不主动接近；沿用既有 enabled:false 语义） |
| `near` | `gap < 240` | `enabled:true` · **反向** · **2.6** |

**粗档推导（必改 2：由 weapon 有效距离取粗档，不做 10% 扫描）**：正式 cannon
`muzzleSpeed 8` × 一轮冷却 `1000ms = 60 步` = **480px 弹道行程** ⇒ `far = 1×`、`near = 0.5×`。
`retreatSpeed = 2.6 > 1.5`：后撤必须**明显快于**对手正常推进，否则相机跟中点 ⇒ 屏幕净位移 ≈ 0
（本项目头号可感知性陷阱），2.6 给出 ≈66px/s 的净拉开速率。

**接线（全部可选、缺省零变化）**：
1. `battleContract.ts`：`BattleConfig.enemyDrive?: EnemyDriveBands` + 转出 `decideEnemyDrive` /

   Body + Wheels，**与相机 `gapWorld` 同源**）+ `enemyDriveState` 只读诊断；
   `if (bands) {...} else { <改前那条指令逐字保留> }`。
3. `testData.ts`：`LabTestEncounter.enemyDrive?: 'keep-distance'` —— **只给 RangedTurret 声明**。
4. `entities.ts`：`SpawnPlan.enemyDrive` **原样透传**（不推断）。
5. `runBattleRuntime.ts`：仅当 **声明存在** 时才把 `{ enemyDrive: ENEMY_KEEP_DISTANCE_BANDS }` 传进正式编排器；
   未声明仍是 `{}`。
6. `encounterLab.ts`：日志区多一行实时档位（页面当场可读）。

⚠️ **门控是「数据声明」不是「按 id / 按 role 推断」**：若按「有弹丸武器 = ranged」推断，
